## Bör åtgärdas:
Tubeless ärver "Hjulet av" från Hjul. Fyll på får alltså fortfarande kombinationsrabatten fast hjulet inte behöver tas av för den. 

- Ringklockan ("Montera övrigt") has no inspection point, so it doesn't show up on Besiktning.
- A finished (locked) Besiktning is never changed. This is so old jobs aren't rewritten when you open them.
- Removing a task from Mottagning: its line disappears, but the ⚠ mark it set stays on the point.
